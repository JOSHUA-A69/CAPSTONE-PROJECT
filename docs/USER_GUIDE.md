I. General Authentication
   A. Registration
      a. Register a New Account
      Navigate to the system's Register page.
      Fill out the required information: Full Name, Email, Phone, Password.
      Click the Register button.
      System validates input and displays a success message.
   B. Sign In
      a. Log Into Account
      Navigate to the system's Log In page.
      Enter registered Email Address and Password.
      Click the Log In button.
      System redirects to the user's specific role Dashboard.

II. Admin
   A. Manage User Accounts
      a. Access User Accounts
      Click "User Accounts".
      System displays list of registered users with Full Name, Email, Role, Status, and actions (Edit, Archive).
      b. Search and Filter Users
      Filter by Role or Search by Name/Email.
      System displays paginated results; query persists.
      c. Create New User
      Click "Add New User".
      System shows form: Full name, Email, Phone, Role, Password, Status.
      Fill out required fields.
      Click "Create User".
      System enforces unique email, validates fields, and displays success messages. New user appears under Active Users.
      d. Edit User
      Click "Edit" on a user.
      System shows edit form (Full name, Email, Phone, Role, Password, Status).
      Click "Update User".
      System displays success messages; updates and permissions are effective immediately.
      e. Archive User
      Click "Archive".
      System moves user to Archives tab. Login for the user is disabled.
      f. Restore User
      Navigate to Archives tab.
      Click "Restore".
      System restores user to Active. Login is re-enabled.
      g. Approve User Account
      Navigate to pending users list.
      Click "Approve" on a new user registration.
      System updates status to Active and sends an Account Activated email.
      h. Manage Profile
      Click "Profile".
      System shows profile fields.
      Update information and save.
      System validates email format/lengths and displays save success.

   B. Manage Organizations
      a. View Organizations List
      Navigate to Manage Organizations.
      System displays all organization records with their adviser assignments.

   C. Manage Reservation Requests
      a. View All Reservations
      Click "All Reservations".
      System displays all reservations with available filters for all statuses.
      b. View Booking Details
      Select a reservation and click "View Details".
      System shows reservation details: service, venue, organization, requestor, and history.
      c. Assign Priest and Approve
      From the details view, select a priest from the dropdown.
      Click Save.
      System updates status to Approved, shows conflict errors if priest is unavailable, and saves success.
      d. Reassign Priest
      Select a new priest from the dropdown.
      System records previous assignment, updates calendars, and sends notifications.
      e. Reject Reservation
      Select a reservation to reject.
      Provide a rejection reason.
      Click Reject.
      System updates status to Rejected, displays success messages, and sends notifications.
      f. Cancel Reservation
      Select a reservation to cancel.
      Provide a cancellation reason.
      Click Cancel.
      System updates status to Cancelled, updates history, displays success messages, and sends notifications.

   D. Manage Services
      a. View Services
      Click "Manage Services".
      System displays all available services with their service name, category, duration, and description.
      b. Add New Service
      Click "Add New Service".
      System shows Create form.
      Fill out details and Save.
      System displays save success, service appears, and service options are updated.
      c. Edit Service
      Click "Edit" on a service.
      System shows Edit form.
      Update details and Save.
      System displays save success and updates are reflected.
      d. Archive Service
      Click "Archive" on a service.
      System moves the Service to Archive.

   E. Generate Report
      a. Access Reports
      Click "Report".
      System loads Reports page, displaying available report types, filter options (date range, organization, service, adviser), and output formats (CSV, Excel, PDF).
      b. Select Report Type and Filters
      Choose a specific report type.
      Apply filters and select desired format.
      System prepares data for generation.
      c. Generate Report
      Click "Generate Report" button.
      System generates selected report based on filters/format and provides a downloadable report file with accurate data.

   F. Manage Liturgical Schedules
      a. View Calendar
      Click "Calendar".
      System displays a calendar of all reservations and schedules.
      b. View Event Details
      Click on an event in the calendar.
      System shows event details, including whether the presider is internal or external.
      c. Change Calendar View
      Click Month, Week, or List.
      System displays events by chosen view.

   G. Manage Venues
      a. View Venues List
      Click "Manage Venues".
      System displays a list of all available venues.
      b. Add New Venue
      Click "Add Venue".
      Fill out venue details (e.g., name, capacity, status) and Save.
      System validates data and displays success message.
      c. Edit Venue
      Click "Edit" on a specific venue.
      Modify details and save.
      System updates the venue and displays success message.
      d. Delete Venue
      Click "Delete".
      System prompts for confirmation. Upon confirmation, venue is removed.

   H. Manage Change Requests
      a. View Pending Change Requests
      Navigate to "Change Requests" module.
      System displays all pending changes requested by users.
      b. View Change Request Details
      Click "View Details" on a request.
      System shows proposed changes alongside original reservation.
      c. Approve Change Request
      Click "Approve".
      System applies modifications to reservation, updates history, and notifies Requestor.
      d. Reject Change Request
      Provide a reason and click "Reject".
      System leaves original reservation intact and notifies Requestor with reason.

   I. Manage Cancellations
      a. View Cancellations
      Navigate to "Cancellations" module.
      System displays pending cancellation requests.
      b. View Details
      Click to open cancellation request details.
      System shows the requested cancellation and reasons provided.
      c. Confirm Cancellation
      Click "Confirm".
      System formally cancels the event and notifies relevant parties.
      d. Reject Cancellation
      Click "Reject".
      System ignores cancellation request and leaves event status as-is.

   J. Manage Elevated Registration Code
      a. View Current Code
      Navigate to Elevated Code module.
      System displays the current Elevated Registration Code used for special role registration.
      b. Update Elevated Code
      Enter a new, secure alphanumeric string (6-50 chars).
      Click "Update".
      System validates input format and updates the code, displaying a success message.

IV. Requestor

      b. Create New Request
      Click "New Request".

      c. Submit Request
      Fill out form and submit.
      System displays success, status becomes Pending, event appears in calendar, and adviser is notified.
      d. Cancel Request
      Click Cancel on a valid request.
      Confirm the prompt.
      System displays success, status becomes Cancelled, and notifications are sent.
      e. Confirm via Link
      Click the confirmation link sent by Staff.
      System processes confirmation; requestor is confirmed at set, allowing staff to proceed.
      f. Submit Change Request
      Submit a request to alter an existing reservation.
      System sends change request pending admin approval, creates history, and notifies admin.
      g. Chat with Admin/Staff
      Click on the Chat icon/button within a reservation's details.
      System opens the chat interface for that specific reservation.
      h. Send Chat Message
      Type a message into the chat input field and click Send.
      System records the message, updates the chat history, and notifies Admin/Staff.
      i. View Chat Responses
      Access the chat interface to read replies.
      System displays the complete conversation history between you and the Admin/Staff.
